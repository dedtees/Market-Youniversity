# Market Youniversity

Homepage concepts for the new Market Youniversity site: the training arm alongside
Pinpoint Promotions & Marketing and Eric Duchin Consulting.

This is a plain static site, so Vercel serves it with no build step.

| Path | What it is |
| --- | --- |
| `/` | Index comparing the four homepage concepts |
| `/concept-1/` | Two doors: individuals and organizations side by side |
| `/concept-2/` | Own the room: presentation skills first |
| `/concept-3/` | Your training team: organizations first |
| `/concept-4/` | Learning path: community, then workshops, step by step |

All pages share `assets/site.css`. The HTML is generated by `tools/build_concepts.py`
(`python3 tools/build_concepts.py .` from the repo root); edit the script and rebuild
rather than editing the HTML by hand.

Placeholders: prices and dates are not set, testimonials are samples, forms don't
submit yet, and the Eric Duchin Consulting link needs its URL. The production site is
planned for WordPress with an LMS; these pages are for choosing the positioning and layout.
